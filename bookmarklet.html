IVI Timestamp Capturer

Перетащи эту ссылку в панель закладок браузера:

⏱ Save Timestamp

Как использовать

  1. Запусти Python сервер: python timestamp_server.py
  2. Открой фильм на ivi.ru
  3. Нажми на закладку "⏱ Save Timestamp"
  4. Таймкод сохранится в ivi_timestamps.xlsx на рабочем столе

Горячая клавиша не поддерживается — только клик по закладке.
